# FitLog 衣码记录 · 使用与二次开发说明

## 一、直接安装使用（最简单）

1. 把 `FitLog-v0.3.2-debug.apk` 传到手机（微信/QQ 文件传输、数据线、或网盘均可）。
2. 手机上打开该文件，允许「未知来源应用安装」后完成安装。
3. 首次打开会提示相册/相机权限，按需允许（不授权也能用，只是不能加图片）。

**支持系统**：Android 8.0（API 26）及以上。

## 二、当前已实现功能

| 页面 | 功能 |
|---|---|
| 首页 | 记录身高/体重/胸围/腰围/臀围/肩宽；每次保存留一条历史快照，可展开查看/删除；最近 5 件衣物快捷入口 |
| 衣物列表 | 关键字搜索（名称/品牌）、按类型筛选（上衣/背心/裤子/高弹短裤/外套/内裤/帽子，自动换行）、卡片直接显示关键三维数据 |
| 新增/编辑 | 选类型自动带出默认属性；可任意增删自定义属性；三档合身评价（紧身/合身/宽松）；相册选图或拍照（最多 9 张，点击设封面） |
| 详情 | 大图查看、完整属性表、备注、删除、复制为新记录 |
| 设置 | 备份导出为 zip（含图片，通过系统分享保存/发送）、导入恢复、按类型添加属性模板 |

**默认属性**：上衣、背心=衣长/胸围/肩宽；裤子、高弹短裤=裤长/腰围/臀围；外套=衣长/胸围/肩宽；内裤=腰围/臀围；帽子=头围/帽檐长。

**隐私**：所有数据只存在手机本地（应用私有目录 + SQLite），无任何联网与上传。

**UI 设计规范（v0.3.1）**：遵循 8pt 间距网格、Material 3 动效 Token（Spring 200/300/400ms）、克制两级阴影、44dp 最小触控区、WCAG AA 对比度、完整深色模式；品牌主色 #3B6FE0 保持不变。

**崩溃排查**：若应用闪退，崩溃堆栈会自动保存到应用私有目录的 `crash_log.txt`。打开 **设置 → 错误日志**，通过系统分享（发到微信/文件传输助手）把该文件发给开发者即可定位问题。

## 三、二次开发（改代码后重新打包）

技术栈：**Kotlin + Jetpack Compose + Room**，工程目录 `FitLog/`。

### 方式 A：Android Studio（推荐，Windows 无管理员权限也能用）
1. 安装 Android Studio（默认安装即可，无需系统管理员权限）。
2. Open → 选择 `FitLog` 目录，等待 Gradle 同步完成。
3. 菜单 Build → Build Bundle(s)/APK(s) → Build APK(s)，即可生成新 APK。

### 方式 B：命令行
```bash
export ANDROID_HOME=<你的 Android SDK 路径>
./gradlew assembleDebug     # 输出 app/build/outputs/apk/debug/app-debug.apk
```

> 注：本仓库未提交 gradle wrapper 的 jar 文件；用 Android Studio 打开时会自动生成，命令行方式可先执行一次 `gradle wrapper`。
