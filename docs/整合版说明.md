# FitLog 衣橱整合版

以 FitLog 原生 Android 为基础，衣物档案同时承载尺码与穿搭信息。保留已有身体数据与历史、照片、分类模板和备份；日常导航为衣橱、搭配、灵感，不包含每日穿着日记。

## 设计方向

Sage & Ivory：背景 #F6F8F3，卡片 #FFFFFF，品牌 #47765D，正文 #20352B，次级文字 #586C5D。以自然、轻盈的个人衣橱为视觉方向；界面标题使用思源宋体，正文使用思源黑体，拉丁标题采用 Newsreader，数字使用 Work Sans。内置字体不需要联网；许可见 fonts 文件夹。品牌色用于选中态和关键操作，页面以中性浅色为主，适配深色模式与系统动画设置。

## 使用路径

1. 衣橱中点击录入：照片和尺寸都是选填；主色可选色块或手工输入，图案与版型可独立填写。
2. 单品详情查看照片、尺码、版型和穿着感受；同类型衣物可进行尺码对照。测量口径、单位不清晰时只并排展示。
3. 点击“用这件搭配”，固定起搭单品，从已有衣物中查看组合，替换或添加，命名保存。可修改或另存，不绑定穿着日期。
4. 配色灵感提供色组和原因，可筛选主色相近的衣物。推荐采用离线启发式颜色规则，不调用 AI；颜色、版型、实际效果都可以自行判断。
5. “我的”包含身体数据历史、衣物属性模板、导入导出备份。备份升级到 v2，包含衣物、照片、身体数据和搭配；导入采用追加方式并重建关联，兼容旧版 v1。

## 安装与数据

`preview` 构建使用 `com.fitlog.app.preview`，与原版 `com.fitlog.app` 共存。先在旧版导出备份，在预览版“我的 → 导入恢复”中选择 ZIP；导入是追加而非覆盖。两者数据各自独立，预览版的修改不会自动同步回旧版。升级并覆盖旧版需要相同签名及更完整的实机迁移验证。

工程使用 Android 8.0+、JDK 17、Android SDK 34；执行 `./gradlew :app:assemblePreview` 和 `./gradlew :app:testDebugUnitTest`。正式应用与预览均不需要账号或网络；依赖下载仅用于开发构建。
