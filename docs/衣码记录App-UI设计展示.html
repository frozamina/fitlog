设计系统落地清单（v0.3.0）

本次按《UI 设计系统》规范对 App 做了全量 UI 交互升级，品牌主色 #3B6FE0 保持不变：
1. 8pt 间距网格：所有间距统一为 4/8/12/16/20/24/32，消除原先随手的 14dp、10dp 等散值。
2. 卡片两级阴影：默认 0 1px 2px + 0 4px 16px（克制两层），按下时阴影归零 + scale 0.985，替代原先的单薄阴影。
3. 动效 Token 化：位移/缩放用 Spring 回弹曲线 cubic-bezier(.34,1.56,.64,1)，尺寸变化用 Emphasized 400ms，纯淡入用 Decelerate；时长档位 200/300/400ms。
4. 44dp 触控底线（Apple HIG）：类型 chip、图片删除"✕"、历史删除按钮全部补足到 44dp，解决原先小按钮难点的问题。
5. 对比度达标：次要文字由 #8A93A6 加深到 #6B7488，满足 WCAG AA 4.5:1；合身标签配文字而非只靠颜色（色盲友好）。
6. 状态完整：新增骨架屏（Loading）、空状态（有温度的空态图 + 引导）、Toast 反馈（保存校验、导入导出结果）。
7. 深色模式：补齐完整深色色板，禁用纯黑，改用带色相深色 + surface 明度分层表达层级。
8. 交错入场：首页/列表项按 45ms 步进依次淡入上移，页面加载不再"一次性砸出来"。
交互细节：① 首页身体数据卡为页面唯一视觉焦点（渐变 + 大字号数字）；② 类型 chip 选中时 Spring 回弹缩放；③ 编辑页属性分组、实时显示"已填 N 项"、保存前校验（名称 + 至少一个尺码）；④ 图片删除按钮扩到 44dp 触控区；⑤ 设置页模板改为可折叠展开（箭头旋转 180°）＋ Toast 反馈；⑥ FAB 与底部栏随路由切换弹入弹出。
